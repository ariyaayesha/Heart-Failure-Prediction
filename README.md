# ❤️ Heart Failure Prediction
### Machine Learning Project for Medical Risk Prediction

**Heart Failure Prediction** is a machine learning project that aims to predict the **risk of heart failure** based on patient clinical data.  
The project uses **data preprocessing, exploratory data analysis (EDA), and supervised machine learning models** to classify whether a patient is at risk of heart failure.

This project is implemented using **Python** and presented in a **Jupyter Notebook** format.

---

## 🎯 Project Motivation

Heart failure is one of the leading causes of death worldwide.  
Early prediction can help doctors and healthcare professionals take preventive actions and improve patient outcomes.

The motivation of this project is to:
- Apply machine learning in the healthcare domain
- Analyze clinical data effectively
- Build predictive models to assist decision-making

## 📂 Dataset Information

The dataset contains **clinical features** such as:
- Age
- Sex
- Chest pain type
- Blood pressure
- Cholesterol
- Fasting blood sugar
- ECG results
- Maximum heart rate
- Exercise-induced angina
- Oldpeak
- ST slope

**Target Variable:**
- `HeartDisease` (0 = No, 1 = Yes)

---

## 🏗️ Project Workflow

1. Import required libraries  
2. Load and explore the dataset  
3. Perform data preprocessing  
4. Visualize important features  
5. Split data into training and testing sets  
6. Train machine learning models  
7. Evaluate model performance
